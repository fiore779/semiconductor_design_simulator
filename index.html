ダイビューへ移動
半導体設計シミュレーター

ショートカット

  • Ctrl+Z: 元に戻す / Ctrl+Y(または Ctrl+Shift+Z): やり直す
  • Ctrl+S: 保存 / Ctrl+O: 開く
  • Esc: ダイアログを閉じる(ダイビューでは選択解除)
  • ダイビュー 2D 編集: 矢印キー=選択ブロックを 1 グリッド移動 / Shift を押しながらドラッグ=スナップなし / ホイール=ズーム / 空きをドラッグ、または Space+ドラッグ=パン
  • ダイビュー 3D 表示: ドラッグ=回転 / ホイール=拡大縮小 / 右・中・Shift+ドラッグ=移動 / 矢印=回転 / +/-=ズーム / 0=リセット / Esc=選択解除 / Shift+クリック=選択の追加/解除(編集は 2D 編集で)
  • /: 部品ライブラリの検索欄へ移動(混合・新規設計のとき)/ 検索欄で Esc: 検索語を消す・Enter: 先頭の部品へ移動
  • ツールバーの「結果」「下段」「配置」: 右の結果・下段(プロパティ/履歴/検証)・中央のダイビューの表示/非表示(状態は保存されます。隠している間は、検証の件数などをボタンのバッジで知らせます)
  • 入力欄にフォーカスがあるときは、ショートカットは無効です。

ブロックの配置は現実の CPU のレイアウトに倣った模式図で、大きさは実測ではありません(実チップのフロアプランではありません)。Uncore・iGPU・NPU は見た目だけの「飾り」で、計算に影響しません。

できること: 混合(C)=部品ライブラリから実在チップの部品を選んで空のダイに置く(性能は確度:低、電力・温度は出さない)。 実在チップを「再現」(A)で読み込み公開値と比べる。「改良」(B)でコア数・クロック・L3 を編集し、元のチップとの差分(性能の予測)を見る。ブロックの位置・大きさの編集(元に戻す対応)。保存と読み込み。
パッケージ設定(冷却・基板・電力制限)と、電力・温度の推定(確度:低・冷却の熱抵抗は仮置き)、電力密度・温度のマップ(模式図)。
D 新規=プロセスとダイ寸法を決めて空のダイを作り、既存コアを「複製して編集」した自作コア(発行幅・ROB・L2・クロック・SMT。面積は範囲、確度は常に低)を置く。
できないこと: 目標性能からの構成の提案、電力・温度・最大クロックの推定(自作コア)、混合による性能低下の反映、面積・公表電力・歩留まりの再計算。電力・温度の制限による性能への反映。
