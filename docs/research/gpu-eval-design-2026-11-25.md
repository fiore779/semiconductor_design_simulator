# dGPU の性能モデル 第 1 段階(RTX 40 シリーズ。2026-11-25)

設計・データ源は `gpu-eval-design-2026-11-20.md`(主 API は OpenCL に決定。§6 に代表 SKU の OpenCL スコア表)。

## データ(data/gpus.js)
- GeForce RTX 4060 / 4060 Ti / 4070 / 4070 SUPER / 4070 Ti / 4070 Ti SUPER / 4080 / 4080 SUPER / 4090 の 9 SKU。
- 仕様(シェーダー数・ブーストクロック・帯域・バス幅・TGP): Wikipedia「GeForce RTX 40 series」(2026-11-25 取得。[二次])。**NVIDIA 公式との照合は未了**。4070 SUPER・4070 Ti の帯域 504 GB/s は表の結合行からの読み取り(4070 と同じ 192bit・21 Gbps)。
- スコア: Geekbench 7 OpenCL チャート(2026-11-20 取得。[公表]。Primate Labs の集計平均)。

## モデル(js/sim/gpuperf.js)
`スコア = u(世代) × TFLOPS^0.69`、`TFLOPS = シェーダー数 × 2 × ブーストクロック / 10^6`。
- 指数 0.69 は 9 SKU の対数最小二乗。TFLOPS が 5.5 倍(4060 → 4090)でスコアは約 3 倍。**演算量に対して強く飽和する**(スコア/TFLOPS は 4060 の 6,426 から 4090 の 3,575 まで単調に下がる)。
- u は世代内の SKU の中央値(CPU の uCal と同方式。**学習内**)。SKU 別の特別係数なし。
- 当てはめ誤差(最小二乗の切片での値): 4060 +0.1%・4060 Ti +9.6%・4070 −4.6%・4070 SUPER −4.5%・4070 Ti +1.7%・4070 Ti SUPER −2.9%・4080 −5.5%・4080 SUPER +0.3%・4090 +6.9%(許容 ±10% 以内。テストは中央値の u で ±10%)。
- 最大の残差は 4060 Ti(+9.6%。128bit・288 GB/s で、演算量の割に帯域が細い)。**帯域キャップが効く SKU**とみられるが、1 世代 9 点では帯域項の係数を決められない(過学習になる)。AMD・Intel・RTX 30/50 を入れてから帯域項を検討する。
