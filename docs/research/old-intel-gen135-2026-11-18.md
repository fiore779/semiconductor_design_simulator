# 第1・第3・第5世代の Core i を追加(2026-11-18)

ユーザー指示「5、3、1世代の core i が追加されていないので追加してください」。`data/presets/chips-old.js` に 5 SKU を追加した(131 → 136 件)。

## 1. 追加した SKU と選び方

| 世代 | SKU | ダイ | GB7(Windows のみの中央値) | 備考 |
|---|---|---|---|---|
| 第1世代 Nehalem(Lynnfield 45nm) | i7-860(4C8T) | 296mm² [二次] | ST 544 / MT 1714(n=14) | 標本は少なめ |
| 第1世代 Westmere(Gulftown 32nm) | i7-980X(6C12T) | 239mm² [二次] | 650 / 3193(n=21) | 3 チャネルメモリ |
| 第3世代 Ivy Bridge(22nm) | i7-3770K(4C8T) | 160mm² [二次] | 849 / 3036(n=52) | |
| 第3世代 Ivy Bridge | i5-3570K(4C4T) | 同じダイ | 809 / 2431(n=44。808.5・2430.5 を四捨五入) | HT 無効・L3 6MB |
| 第5世代 Broadwell-H(14nm) | i7-5775C(4C8T) | 182mm² [二次] | 1351 / 4949(**n=7**) | 標本が非常に少ない。公式チャートは 1338 / 4980 で近い値 |

取得は 2026-11-18、Geekbench Browser v7 検索(q=SKU 名)の Windows の行のうち SKU 名が完全一致のもの(最大 200 件。ここでは全件が 200 未満)。手順は `docs/research/old-intel-windows-median-2026-11-17.md` と同じ。

**入れなかった SKU**
- **i7-920(Bloomfield)**: Windows の標本 22 件のうち 17 件がオーバークロック(動作クロック 3.6〜4.1GHz。定格は 2.66GHz)で、定格の標本が 5 件しかない。公開値として使えない。
- i5-750・i7-870・i7-930 ほか(n=3〜10)・i5-5675C(n=3): 標本が少ない(ユーザー方針「データが多くないものは入れるべきではないかもしれません」)。
- 第5世代で他のデスクトップ SKU はない(Broadwell のデスクトップ向けは i7-5775C と i5-5675C だけ)。i7-5775C は標本が 7 件と少ないが、第5世代の唯一の代表として入れた(ST・MT は公式チャートとも 1% 以内で一致)。

## 2. 構成・クロック・電力

- **第3・第5世代(i7-3770K・i5-3570K・i7-5775C)**: Intel ARK(2026-11-18 取得。intel.com の製品ページ)。[公表]。ARK は L3 の段階を明記せず「Intel Smart Cache」と書く。
- **第1世代(i7-860・i7-980X)**: Intel の製品ページが取得できず(古い SKU の ARK ページは 404)、構成・クロックは Wikipedia の Core i7 一覧と検索の要約、TDP は 860 が 95W、980X が 130W(Intel の製品概要の検索抜粋)。[二次]。メモリは 860 が DDR3-1333 の 2 チャネル、980X が DDR3-1066 の 3 チャネル(Wikipedia)。
- **全コアクロック(allCoreGHz。MT の予測に使う)**: i7-860 は 2.93GHz(AnandTech のターボ表の検索抜粋)、i7-3770K は 3.7GHz(WikiChip の 4 コア時ターボ)、i7-5775C は 3.6GHz(同)。i5-3570K(CPU-Monkey は 4 コア 3.8GHz だが 1 コア値と同じで疑わしい)と i7-980X(6 コア時の値が未取得)は未設定で、boost を使う。

## 3. uarch(`data/uarch.js`)

| uarch | 値と出典 |
|---|---|
| Nehalem(Westmere も同じ名前) | 幅 4・ROB 128(bit-tech「96 → 128」。stuffedcow が Lynnfield で 128 と実測)・L1D 4・L2 10 サイクル(講義資料・AnandTech)・AVX なし。L3 遅延・分岐ミス罰則・MSHR は出典が取れず未設定 |
| Ivy Bridge | 幅 4・ROB 168(stuffedcow の実測)・分岐ミス 14・L1D 4・L2 12(設計書 §2.8.3)・L3 30 サイクル(7-cpu.com の i7-3770 の 26〜34、平均 29.4〜30.4)・AVX |
| Broadwell | 幅 4・ROB 192(Haswell から据え置き。WikiChip のノート・AnandTech の Xeon E5 v4 記事。[二次])・分岐ミス 15・L1D 4・L2 12。L3 遅延は未設定(59 サイクルの測定は HEDT 機で、クライアントは未取得) |

ST の補正 u(uCal)は、SKU 別 u(補正 100 での予測を割った値)の中央値: Nehalem 78.4(860・980X の 2 件)、Ivy Bridge 91.4(3770K・3570K の 2 件)、Broadwell 154.9(5775C の 1 件。eDRAM L4 の効果を含む)。いずれも学習内で、検証ではなく、標本が少ない。

## 4. 再現度(公開値との差。学習内)

| SKU | ST 誤差 | MT 誤差 |
|---|---|---|
| i7-860 | +6.5% | +6.2% |
| i7-980X | -5.8% | -9.3%(境界) |
| i7-3770K | -0.6% | -3.9% |
| i5-3570K | +0.4% | +9.8%(境界。HT なしの過大の傾向。docs/research/old-intel-mt-ng-2026-11-17.md) |
| i7-5775C | 0.0% | -3.2% |

全 5 件が ST・MT とも ±10% 以内。i7-860 の MT は全コアクロックを入れる前は +20.6%(boost 3.46GHz で計算)だった。i7-980X の MT が低めなのは、6 コアの伸び方が σ の式より大きいため(σ・γ の再校正が要る可能性。専用の係数は入れない)。

- ブラウザ上のアプリでの描画は確認していない(テストで枠・重なり・合計の検査まで)。

## 6. 限界

- 第1世代は Intel ARK が取れず [二次]。ダイ面積(296・239mm²)は Kurnal の実測ではない。
- Nehalem の L3 遅延・分岐ミス罰則・MSHR は未設定のため、ST の補正 u に含まれる。
- Broadwell の eDRAM(128MB の L4)はモデルに入っていない。別の 22nm ダイ(77mm²)の面積も含めていない。
- i7-5775C の公開値は標本 7 件(公式チャートとは近い)。i7-860 も 14 件と少ない。
