## 調査 1: Meteor Lake の GB7 データと公式スペック

### 1.0 既存データとの重複確認

- `data/presets/chips-pc.js` に入っている Meteor Lake は **Core Ultra 9 185H(id `intel-mtl-185h`)の 1 件だけ**(calib: false)。
- `data/benchmarks/gb7-scores.js` には 185H と **Core Ultra 5 135U(「Meteor Lake: Core Ultra 5 135U(2.1GHz, 12c)」、[チャート] 1710 / 7817)** の 2 件がある。135U はプリセットにはない。
- `docs/設計書.md` §2.4(301〜302 行目)は 185H(2035 / 12682、[実測] Windows n=200、2026-11-13)と 135U(1710 / 7817、[チャート])。同書 2075〜2078 行目の「Redwood Cove の標本を増やせる SKU」の表に 165H・155H・125H・135U・155U の旧値(OS 混在の n=21〜25)が一覧だけある(プリセット化はしていない)。
- 185H の ARK 値(P 2.3/5.1、E 1.8/3.8、LP-E 1.0/2.5GHz、L3 24MB、PBP 45W、MTP 115W、最小保証 35W、LPDDR5X-7467 / DDR5-5600、最大 96GB・2ch)は今回の取得と一致した。

### 1.1 GB7 の取得方法

- 前例(docs/research/gb7-windows-only-2026-11-13.md、hx-sample-gb7-2026-11-11.md)と同じ方式。`https://browser.geekbench.com/v7/cpu/search?q=<SKU名>&page=N`(25 件/ページ、新しい順)を Chrome の同じタブから順に取得し、Platform 列が `Windows` の行だけを集めた。直近から Windows 200 件で打ち切り(最大 24 ページ)。200 件に届かないものは検索結果の全件を読んだうえでの件数。
- SKU の一致: プロセッサ名が `Intel <SKU名>` と完全一致する行だけ。今回の検索では別名の混入は 0 件だった。
- ST / MT は中央値(偶数件は中央 2 件の平均)。n < 30 は **[低信頼]**。
- 「フルコアのみ」は、コア数表示がその SKU の総コア数と一致する行だけの中央値(VM などでコア数が少ない投稿を除いたもの)。参考として備考に書いた。

### 1.4 Redwood Cove の uCal 用に使えるか(判断)

- **使える(n ≥ 30、ARK も取得済み)**: 165H(n=163)、155H(200)、135H(136)、125H(200)、165U(118)、155U(200)、135U(161)、125U(200)、115U(73)。164U は n=30 で境界(使えるが件数は少ない)。
- **使えない / 低信頼**: 134U(n=11、[低信頼])。HL・UL の全 SKU と 105UL は GB7 の投稿が 0 件。
- 185H と同じ 6P+8E+2LP-E 構成で、差がクロックと電力だけなのは 165H・155H。4P の 135H・125H、2P の U 系は P 数が違う。
- ダイ面積: 6P+8E の compute タイル(185H と共通)は既存値がある。U 系(2P+8E)と 115U・105UL(2P+4E)の compute タイル面積は既存の調査(設計書 2131 行目)で未取得のまま。今回も調べていない。
- 1.2 の注意のとおり、ST の中央値が P 最大ターボの順と合わない SKU(135H > 155H、155U < 125U)がある。uCal に使う場合は、投稿機の電力設定の差が入っていることに注意が要る。

### 2.3 候補値(PPT 230W 既定での全コアクロック)

- **第 1 候補: 5.0GHz [二次]**。KitGuru の全コア平均「just over 5GHz」(Cinebench R23 10 分ループ、360mm AIO、215W)。5950X の allCoreGHz と同じ出典・同じ測り方(KitGuru の Cinebench 全コア)なので、条件がそろう。TechSpot の CCD 別 5.1 / 4.9GHz(単純平均 5.0)、FoneArena の定常 5.0GHz とも整合する。
- 第 2 候補: 5.05〜5.1GHz [二次]。FPS Review の 5.075〜5.150GHz の中央は 5.1125GHz、Gamers Nexus の Blender 約 5.1GHz。KitGuru の CCD0 / CCD1 の平均(5.1 と 4.97 の平均)は 5.035GHz(計算値)。
- **第 3 候補(ユーザー提示の出典): 5.24GHz [二次]**。TechPowerUp の冷却要件の記事の 32 スレッド・420mm AIO の値(空冷 NH-U14S ファン 100% なら 5.171GHz)。強み: 表になっていて数値がはっきりしており、冷却の違いが分かる。弱み: 負荷の名称と計測時間が書かれておらず、PPT の明記もない。Cinebench を 10 分〜1 時間回した他の出典(4.9〜5.15GHz)より高いのは、負荷の種類または時間の違いの可能性がある(推測。未確認)。GB7 の MT は短い負荷なので、この値の方が GB の実行中に近い可能性もある(推測。未検証)。
- どれを採るかは判断が要る: 5950X の前例(KitGuru の Cinebench)とそろえるなら 5.0GHz、冷却の良い条件での短めの負荷を重く見るなら 5.24GHz(空冷なら 5.17GHz)。
- boost 5.7GHz との比: 5.0 / 5.7 = 0.877(計算値)。5950X の 3.925 / 4.9 = 0.801 より boost に近い。

使える / 使えないの判断:
- **使える**: KitGuru(全コア平均として明記、負荷・時間・冷却・電力がそろう)、FPS Review(範囲として明記、負荷・時間・冷却がそろう)、TechSpot(CCD 別。平均は計算が要る)。
- **参考のみ**: SkatterBencher(Prime95 は GB の MT より明らかに重い。カスタム水冷)、Gamers Nexus(条件の記載がない)、FoneArena(負荷不明、240mm AIO)。
- **注意**: どの出典も GB7 の MT 実行中のクロックではない。GB の MT は Cinebench より負荷が軽く短いので、実際のクロックはこれより高い可能性がある(推測。未検証)。5950X は同じ Cinebench 基準で入れて +23.0% → +3.5% になった前例がある。7950X に 5.0GHz を入れたときの MT 誤差は、この調査では計算していない。
