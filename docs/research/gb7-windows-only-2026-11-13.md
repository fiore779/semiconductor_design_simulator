# PC 系 CPU の Geekbench 7 公開値を Windows のみの中央値で取り直す(2026-11-13)

取得日: 2026-11-13。区分: [実測](Geekbench Browser の公開投稿の中央値)。プリセット・データにはまだ入れていない(調査のみ)。

## 取得方法

- Geekbench Browser の検索 `https://browser.geekbench.com/v7/cpu/search?q=<SKU名>&page=N`(25 件/ページ、新しい投稿順)を Chrome の同じタブから順に読み、各行の「Platform」列が `Windows` の行だけを集めた。直近から Windows 200 件に達した時点で打ち切り(最大 24 ページ=600 件まで)。200 件に届かない SKU は取れた件数 n を書き、n < 30 は [低信頼]。
- SKU の一致: 各行のプロセッサ名(`list-col-model` の 1 行目)が `<ベンダー> <SKU名>` と完全一致するものだけ(AMD の「 8-Core Processor」「 w/ Radeon …」等の後置だけは許容)。7945HX と 7945HX3D、14700K と 14700KF、2700X と PRO 2700X 等は別名として除外。
- ST / MT はそれぞれの中央値(偶数件は中央 2 件の平均)。
- 現行公開値は `data/benchmarks/gb7-scores.js`(プリセットの `gb7` 名で照合)。区分「チャート」は Geekbench 公式チャートの値、「直近25件の中央値」は OS 混在の直近 25〜200 件の中央値。差 = Windows 中央値 / 現行 − 1。
- 備考の「コア数」は Windows 行のコア数表示の内訳(仮想マシン等でコア数が少ない投稿も名前が一致すれば含めている)。

### 気づいた点
- 「チャート」区分のデスクトップは Windows 中央値との差がおおむね ST +0〜4%・MT ±5% 以内。例外は 13600K(MT +11.1%)・14600K(MT +5.3%)・13700K(MT +5.6%)。
- 差が大きいのは現行が OS 混在の直近 25 件前後の SKU(7735HS・350・HX 370・185H・325 等)で、標本の小ささが主因と見られる(推測。OS 別の比較はしていない)。
- 現行が OS 混在 200 件の HX 系のうち、14900HX だけ差が大きい(+5.6% / +9.8%)。2026-11-11 の記録(hx-sample-gb7)でも Windows のみは 2567.5 / 18866.5 で、今回と近い。13980HX・7945HX・275HX・14700HX・285H は ±5% 以内。
- コア数表示が少ない投稿(VM 等)が混ざる SKU がある: 7950X(20/200)、9950X(21/200)、358H(22/200)、285H(12/200)。名前が一致すれば含めた(取り方の指示どおり)。フルコア表示のみの中央値を備考に併記した(358H は MT が 16289 → 16802.5 と +3.2% 変わる。他は ±1.6% 以内)。
