# Ryzen 5 8500G・Ryzen 7 8700G(Phoenix のデスクトップ APU)のプリセット追加(2026-11-16)

ユーザー指示「8500G、8700G を追加してください」(直前の質問「Ryzen 5 7545U よりも一般的なものはないですか」への回答)。あわせて、ユーザー決定「7545U はなくていい(一般的でないため)」により 7545U を外した。取得日はすべて 2026-11-16。区分: [公表] = AMD 公式の製品ページ / [実測] = Geekbench Browser から自分で集計した値 / [推定] = 流用・代用。

## 2. GB7(Windows のみ・名前と構成が完全一致)

Geekbench Browser v7 の検索 `q=Ryzen+5+8500G`・`q=Ryzen+7+8700G` を Chrome のページ上から fetch → DOMParser で読んだ(設計書 §2.4 と同じ方法)。

| SKU | 検索の全行 | Windows | 採用(名前・構成が完全一致) | ST 中央値 | MT 中央値 |
|---|---|---|---|---|---|
| 8500G | 159 | 138 | **132**(「Ryzen 5 PRO 8500G」と 6 コア以外の行を除外) | **2361** | **10631** |
| 8700G | 375 | 138 | **132**(「Ryzen 7 PRO 8700G」と 8 コア以外の行を除外) | **2352** | **14128.5 → 14129** |

- どちらも n=200 に届かないので、Windows の全件を使った(n=132)。
- 標本のばらつき(10〜90 パーセンタイル): 8500G ST 1888〜2462・MT 8854〜11517、8700G ST 1960〜2455・MT 10579〜16058。8700G は報告クロックが 4200MHz の行が 122 件・4801MHz の行が 10 件。
- 投稿日: 8500G 2026-07-23〜2026-11-15、8700G 2026-08-05〜2026-11-16。

## 3. 試算(再現モード)

| | ST モデル / 公開値 | ST 誤差 | MT モデル / 公開値 | MT 誤差 |
|---|---|---|---|---|
| 8500G | 2372.7 / 2361 | **+0.5%** | 10106.3 / 10631 | **-4.9%** |
| 8700G | 2415.9 / 2352 | **+2.7%** | 14132.3 / 14129 | **+0.02%** |

- すべて ±10% に入る(ok)。デスクトップは電力が固定(TDP 65W)なので、ノート(7545U)で出た「cTDP 上限と実機の電力の食い違い」は出ない。allCoreGHz は要らなかった(入れていない)。
- dramLat: 7840HS の 103.3ns(Chips and Cheese、SO-DIMM DDR5-5600 のノート)を代用 [推定]。デスクトップの UDIMM DDR5-5200 の値は未取得で、メモリの違いは補正していない。
- 既存 111 件の評価(再現・改良 222 件)は 1 件も変わらない(7545U の 2 件を除いて前後比較)。calib:false で校正(σ・u・c)に入らない。

## 4. 7545U を外した件

直前に追加した Ryzen 5 7545U(Phoenix 2 のモバイル。GB7 は Windows 14 件・ミニ PC 2 系列のみで MT -14.1%)は、ユーザー決定「7545U はなくていい(一般的でないため)」で外した。専用のデータ(GB7 の行・memory・caplayouts・floorplan・blocklib の専用行・テストの期待・baseline)を削除した。Zen 4c の uarch・blocklib の Zen 4c 面積(2.48mm² 流用)・Phoenix 2 のダイ定義は 8500G が使うので残した。7545U の調査結果は `docs/research/phoenix2-2026-11-16.md` に経緯として残している。

## 5. 未取得・判断待ち

- Zen 4c の IPC の実測、Phoenix 2 のコア面積の測定(8500G は Zen 4c 面積を AMD の Bergamo の公表値で代用)。
- 8000G の全コアクロックと、UDIMM DDR5 での DRAM 遅延。
- AM5 の APU のパッケージ(コンデンサ配置は写真がなく `unknown`。Raphael・Granite Ridge の `am5` の配置は 2 チップレット構成の写真から作ったもので、モノリシックの APU に当てはまるか未確認)。
- 8300G(Phoenix 2 の 4 コア)・8600G(Phoenix 1 の 6 コア)は今回は入れていない(ユーザー指示は 8500G・8700G)。
