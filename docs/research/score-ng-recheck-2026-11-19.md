## 2. 古い SKU の MT が高く出る原因(今回の新しい分析)

MT の予測は「コアごとの ST × コア数 × SMT × η、η = 1/(1+σ(スレッド数−1))」。コアごとの ST は補正 u で公開値に合わせてあるので、**MT の誤差は η の差そのもの**。各 SKU で「公開値の MT ÷ Σ(コアごとの ST)」(= 実際の η)と、モデルの η の比を出した(1.0 なら一致):

| グループ | η の実測 ÷ モデル |
|---|---|
| L3 なし(Core 2・NetBurst・Trinity) | Q6600 0.70 / Q9550 0.81 / Q9650 0.82 / Pentium D 820 0.84 / A10-5800K 0.85 / E8400 0.86 / Pentium D 945 0.91 / Cedar Mill 631 0.91 / Prescott 531 0.92 |
| L3 あり・Bulldozer 系ではない古い SKU | Agena 1.03 / Deneb 0.93 / Thuban 0.91 / Sandy Bridge〜Skylake の HT なし 0.91〜0.95 |
| Bulldozer 系(L3 あり) | FX-8150 0.83 / FX-8350 0.84 / FX-6300 0.77 |
| 現行(Zen・Alder Lake 以降・Snapdragon 8 系) | 0.92〜1.15(おおむね 1.0 前後) |

- **L3 のない SKU は η が系統的に低い**(平均 0.85)。最後段のキャッシュがなく、全コアの L2 ミスが共有のメモリ(FSB)へ行って取り合うためと考えられる。設計書 §5.2.2 の「メモリ帯域の頭打ち」は未実装なので、この効果をモデルが持たない。η から σ を逆算すると 0.095〜0.235(中央値 0.135。現在の σ は 0.0315)と、SKU でばらつく(FSB 1066MT/s の Q6600 が最悪、FSB 800MT/s の Pentium D は 2 コアなので軽い)。**1 つの定数では説明しきれない**。
- **Bulldozer 系**は L3 があっても η が 0.77〜0.84。1 モジュールの 2 つの整数コアが先読み・デコード・浮動小数点・L2 を共有するため(Agner Fog 第 21 章)。整数コア 1 つを 1 コアと数えても、1 モジュールを 1 コア 2 スレッドと数えても合わない(前者 +18〜30%、後者 −12〜−20%)。
- 上のどちらも、メモリ帯域の頭打ち(§5.2.2)かモジュール共有の表現を入れないと、特別な係数なしには直せない。**今回はモデルを変えていない**(ユーザー方針: SKU 専用の係数を持たせない。古いチップは誤差を出す必要がない)。

## 3. 取れる対策(未実施。希望があれば)

1. **L3 なしのコアに MT の σ を上乗せ**(σ_noL3 ≈ 0.13。上の 9 件の中央値)。試算では L3 なしの 9 件が ±12% 以内に入る(Q6600 +12%、Pentium D 820 +9%)。現行のプリセットで L3 がない(cfg.l3MB = 0)ものは古い SKU だけなので、現行の結果は変わらない。出典のある物理量ではなく、古い 9 件への当てはめ(学習内)になる。
2. **メモリ帯域の頭打ち(§5.2.2)の実装**。FSB・DDR の帯域と、ST の ST 1 つあたりの帯域消費(出典なし)が要る。大きな変更。
3. **Bulldozer のモジュール共有**を表現する係数(整数コア 2 つの MT 寄与を uarch の値として持つ)。FX・A10 だけに効く。
