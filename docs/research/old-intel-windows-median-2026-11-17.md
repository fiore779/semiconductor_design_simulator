## 読み取れること

- **9700K**: Windows のみ・n=200 の中央値は ST 1669.5・MT 8224(チャートは 1659・8031)。MT のモデル誤差は +11.8% → **+9.2%**(±10% 以内)。ただし +9% の過大は残る。チャート値の偏りは一部で、原因の全部ではない。
- **SMT なしの 5 件(2500K・4690K・6600K・7600K・9700K)**: MT のモデル誤差の平均はチャート基準 +7.6%、Windows 基準 +9.1%。取り直しても偏りは消えない(むしろ大きくなる) = チャート値の偏りが主因ではない。
- **標本の少ない SKU**: 2720QM は n=5(ST が +27.6% 動く)、4700HQ は n=13、7600K は n=26、2500K は n=29。ユーザー指摘「あまりデータが多くないものは入れるべきではない」に当たる候補。
- 全体: Windows 基準にすると、uCal(チャート ST から決めた値)が合わず ST の誤差が増える(MAE 1.02 → 3.58%。主に 2720QM・4700HQ の小標本)。全 SKU を Windows 基準にするなら uCal の再計算が要る。
