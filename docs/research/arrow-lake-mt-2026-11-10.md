# Arrow Lake(285K・265K)の MT 過大の調査(2026-11-10)

285K の MT +14.9%、265K +13.1%(調査前)。同じ uarch の ST は合っているのに MT だけ過大。順に切り分けた。

## 1. 切り分け(数値)

| 項目 | 結果 |
|---|---|
| ST | 285K -0.3%、265K 0.0%(Lion Cove は 265K が ST の校正代表)。**ST は問題なし**(MT だけの問題) |
| 比較: SMT ありの同世代 | 12900K MT +6.9%、13900K -3.8%、14900K +2.6%、13700K -1.9%、14700K -0.2% |
| 比較: SMT なしのモバイル | 268V(LNL。P4 + Skymont の LP-E 4)-4.8%、388H(Cougar Cove 4P+8E+4LP-E。SMT なし)-0.3%、185H -0.1%。モバイルは別の係数(電力の連続式)で合っているので比較は参考(275HX〔Arrow Lake-HX。16E〕は +29.9% で、こちらは電力の連続式の限界) |
| 285K の MT の内訳 | P 8 コア × 2397 = 19,176、E 16 コア × 1859 = 29,744(**E が 61%**)。合計 48,920 × η(24 スレッド、σ 0.0289 → 0.601)= 29,398 |
| Skymont の u・IPC | E の補正は x86 の ISA 平均 u(106.8)。Skymont/Gracemont の 1 コア比 1.44(クロック比 4.6/4.4GHz を除くと IPC 比 1.38)で、Intel の主張(Skymont は Crestmont 比 +38% 整数)と矛盾しない。LNL の LP-E(Skymont)は 268V で -4.8% と合っており、E 側の u の異常を示す証拠はない |
| L3 遅延 | Lion Cove 84、Skymont 69 サイクル([二次] Chips and Cheese。2026-11-07 に設定済み)。変えても効果は ±2%(2026-11-07 の測定) |
| Geekbench の公開値側 | 285K の GB7 は 25589([チャート]、n 不明)。Geekbench Browser は 403(curl)で OS 別・n を再取得できなかった。チャート値自体にも不整合の兆しがある(14900K 21921 < 13900K 22826)が、検証できない |

## 2. 原因として特定できたもの: 全コア実測クロック(出典つき)

TechPowerUp のレビュー(Overclocking, Boost & Clock Frequencies。取得日 2026-11-10、[二次])の BIOS の画面と本文:
- 285K: 「1 core active, under 70°C = 5.7GHz / 1 core active over 70°C, or 2 cores active = 5.6GHz / **3 or more cores active = 5.4GHz**」「**The E-Cores are basically running at 4.6 GHz all the time**」。https://www.techpowerup.com/review/intel-core-ultra-9-285k/29.html
- 265K: 「1 or 2 cores active = 5.5GHz / **3 or more cores active = 5.2GHz**」「E-Cores are basically running at 4.6 GHz all the time」。https://www.techpowerup.com/review/intel-core-ultra-7-265k/29.html

プリセットの P boost は ARK の Performance-core Max Turbo(285K 5.5、265K 5.4)で、MT の全コア負荷では実際はそれより低い(285K 5.4、265K 5.2)。E は 4.6 のまま(boost と同じ)。

**実装**: 285K の P に `allCoreGHz` 5.4、265K の P に 5.2(任意項目。2026-11-10 の 5950X と同じ仕組み)。結果: 285K MT +14.9% → **+14.2%**、265K +13.1% → **+11.5%**。ほかの SKU の予測は 1 件も変わらない(悪化する SKU なし。ST も不変)。MT の ±10% 外の件数は変わらない(285K・265K とも ng のまま)。

## 3. 原因として強く疑われるが、出典つきの実測がなく入れなかったもの: SMT の効果 γ

残りの +14% / +12% は、**SMT なしの P コア**に効く γ(SMT で増えるスループットの割合。未校正の既定値 0.25)に強く依存する。校正の代表(1800X・5800X・7700・9700X)は**全部 SMT あり**で、σ と γ は分離できない(代表の対数誤差 rms は γ によらず 0.0370 で同じ=縮退している)。Arrow Lake は x86 で唯一 SMT なし(P)で、γ の影響が逆向きに出る。γ を動かして σ を代表で決め直した結果(上の allCoreGHz 反映後。MT 誤差 %):

| γ | σ | 285K | 265K | 12900K | 13900K | 14900K | 13700K | 14700K | 7950X | 9950X | 5950X | 1500X |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 0.25(現在) | 0.0289 | +14.2 | +11.5 | +6.9 | -3.8 | +2.6 | -1.9 | -0.2 | +6.5 | +7.5 | +3.5 | -9.8 |
| 0.30 | 0.0327 | +8.5 | +6.5 | +4.3 | -7.6 | -1.4 | -4.3 | -3.4 | +4.3 | +5.2 | +1.3 | -8.2 |
| 0.325 | 0.0346 | +5.8 | +4.2 | +3.1 | -9.3 | -3.3 | -5.4 | -4.9 | +3.2 | +4.2 | +0.3 | -7.4 |
| 0.35 | 0.0365 | +3.3 | +1.9 | +2.0 | -10.9 | -5.0 | -6.4 | -6.4 | +2.3 | +3.2 | -0.6 | -6.7 |

26 件の x86 デスクトップ(GB7 マルチのあるもの)での MAE: γ 0.25 → 5.16、0.275 → 4.76、0.30 → 4.48、0.325 → 4.28、0.35 → 4.23、0.375 → 4.22、0.40 → 4.47(±10% 外は 2 → 1 → 1 → 1 → 2 → 2 → 2 件。MAE は allCoreGHz 反映前の計算)。γ ≈ 0.30〜0.325 で Arrow Lake も他の x86 デスクトップもすべて ±10% に入る。

**入れなかった理由**: γ は出典つきの実測がない。校正の代表で決まらない値を、検証用の SKU(Arrow Lake と Raptor Lake)に合わせて動かすのは「推測で係数を動かさない」に反する(γ を決めるには SMT あり/なしの同一チップの比較などの実測が要る)。**判断待ち**として設計書 §13.4 に登録した。

## 4. 検討して原因でないと判断したもの

- **E コアの u**: 上記のとおり矛盾なし。LNL の LP-E で合っている。
- **η をスレッドでなくコア数で決める**: 13900K(32 スレッド・24 コア)が -3.8% → +9.7% と悪化する。
- **L3 遅延**: ±2%。
- **メモリ**: 285K は DDR5-6400 2ch で基準構成。補正は 1.0。
