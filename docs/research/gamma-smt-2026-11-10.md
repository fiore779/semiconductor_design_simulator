# SMT の効果 γ を 0.30 に変更して全体を再校正(ユーザー判断 A。2026-11-10)

`docs/research/arrow-lake-mt-2026-11-10.md` で、Arrow Lake(285K・265K)の MT 過大の残りは SMT なしの P に効く γ(SMT の効果。既定値 0.25)への依存と特定したが、γ に出典つきの実測がないため未修正にしていた。ユーザーが選択肢 A(γ を 0.30 にして全体を再校正)を選んだ。

## 1. 変更内容

- **γ(`MT_DEFAULTS.gammaSmt`)0.25 → 0.30**。**[推定・校正値]。出典のある実測ではない**。決め方: x86 デスクトップ 26 件(GB7 マルチのあるもの)の MT 誤差の MAE で選んだ(γ 0.25 → 5.16、0.275 → 4.76、0.30 → 4.48、0.325 → 4.28、0.35 → 4.23、0.375 → 4.22、0.40 → 4.47。±10% 外は 2 → 1 → 1 → 1 → 2 → 2 → 2 件)。MAE の最小は 0.35〜0.375 だが、SMT ありの Intel(13900K -10.9% など)が ±10% に近づくため、±10% 外が最少の範囲(0.275〜0.325)の中で Arrow Lake が ±10% に入る最小の 0.30 を採った。校正の代表 4 件は全部 SMT ありで、代表の対数誤差(rms 0.0370)は γ によらず同じ=γ は代表では決まらない。**検証用の SKU(Arrow Lake と Raptor Lake)に合わせた値**。
- **σ を新しい γ で代表から決め直し**: 0.02888 → **0.03270**(代表は x86 の 4 件のまま)。
- **スマホ SoC の MT 係数 0.91 → 0.94**: σ・γ が変わると MT の絶対値が変わるため、同じ 18 件で逆算し直した中央値 0.936(範囲 0.767〜1.065)。
- **mobile-pc の連続式 c 0.429 → 0.443**: p を 0.10〜0.325 で走査し直しても LOO 最小は p = 0.15(LOO 0.0787、標本内 0.0752。一律 0.81 は標本内 0.0911)で、指数は 0.15 のまま。k_i ÷ W_i^0.15 の中央値は 0.4431(小数 3 桁で 0.443)。
- ST は不変(γ・σ は MT だけに効く)。

## 2. 影響

- ±10% 外(全プリセット・ST と MT の延べ): **24 → 22 件**(MT のみ 14 → 12 件)。
- **ng→ok(5 件)**: 285K(+14.2% → +8.5%)、265K(+11.5% → +6.5%)、7735HS(-11.1% → -9.0%)、865(-10.1% → -9.6%)、8+ Gen 1(-10.0% → -9.4%)。
- **ok→ng(3 件、悪化。ユーザー決定 A なので実装して報告)**: i3-12100(+9.0% → +10.9%)、780G(+9.6% → +10.3%)、GB10(-9.6% → -13.6%)。i3-12100 は SMT ありの 4P(L3 のある小構成)で、γ を上げて σ が増えると高めに出る。GB10 は SMT なし(X925・A725)で、SMT ありの代表で σ を決め直すと下がる。
- **Arrow Lake 以外への影響(SMT ありの Intel が下がる)**: 13900K -3.8% → -7.6%、13700K -1.9% → -4.3%、14700K -0.2% → -3.4%、14600K -4.1% → -6.1%、EPYC 7401 -5.7% → -8.8%(いずれも ±10% 内)。AMD の 7950X・9950X・5950X は上がる側(+6.5% → +4.3% など。改善)。
